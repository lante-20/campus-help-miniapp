# 湖南好学院 · 校园公益互助小程序（原生微信小程序代码）

## 一、怎么跑起来 / 上传发布

1. 电脑安装「微信开发者工具」（稳定版，免费）：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 打开开发者工具，用你本人微信扫码登录。
3. 选「导入项目」→ 目录选这个 `wechat-miniprogram` 文件夹 → **AppID 填你自己的小程序 AppID**（在 project.config.json 里把「请替换成你自己的小程序AppID」改掉，或导入时填）。
4. 工具里点「编译」，左侧模拟器就能看到首页（任务大厅）。
5. 确认无误后，点右上角「**上传**」→ 填版本号（如 1.0.0）。
6. 浏览器打开 https://mp.weixin.qq.com → 「版本管理」→ 找到刚上传的开发版本 →「**提交审核**」，备注写：
   「纯公益校内代拿/失物信息展示平台，不涉及资金交易，个人主体。」
   服务类目选「教育 / 公益」。
7. 审核通过（1–3 天）后点「**发布**」，小程序上线。

## 二、目录说明
- app.json：页面路由、底部四个 tab（首页/发布/消息/我的）、浅蓝色导航。
- app.js：已填入你的云环境 envId `helpgirl-d5g7bfj4vc612c02a`。
- pages/：首页、发布、详情、接取、消息、聊天、我的、我发布的、我接的、管理员、用户协议、隐私政策。
- utils/sensitive.js：敏感词拦截（代课/代签到/代刷课/代考试）+ 手机号正则拦截。

## 三、当前状态
- UI 全部可点，先用示例数据演示；首页筛选、发布风险弹窗、敏感词拦截、聊天手机号拦截都已生效。
- 数据库读写已预留云开发入口（wx.cloud）。当前为前端演示版，提交审核前建议在开发者工具「云开发」里把任务读写接上（集合名：users / tasks / messages / reports）。
- 报酬仅文字展示，平台不碰资金；不展示手机号；任务卡片展示发布者微信号供双方私下沟通。
